Esse será um projeto para ajudar alunos do ensino médio a aprenderem suas matérias usando a metodologia de flashcards com perguntas e respostas, além de um resumo com a explicação mais detalhada sobre cada pergunta.
Contará com diversas matérias, podendo ser inseridas novas perguntas, respostas e resumos.
Deve ser capaz de mostrar imagens, gráficos e diagramas.
